# Changelog

All notable release-level changes to Message Easy Mode (MEM) are recorded here.

This changelog is intentionally concise. Operator guidance, installation procedures, migration instructions, and troubleshooting belong in the official documentation at https://messageeasymode.com/docs.

Version numbers continue the existing product lineage: Matrix Easy Mode 0.1.x was renamed to Message Easy Mode for the 0.2.x line.

## [0.2.0] - Unreleased

First Message Easy Mode release in the 0.2.x line and the first public source release under the `message-easy-mode/mem` repository identity.

Highlights include:

- the product rename from Matrix Easy Mode to Message Easy Mode;
- guided Control Plane setup and runtime management;
- Matrix/Element stack lifecycle management;
- domains, DNS-backed certificate issuance, renewal, and routing workflows;
- shared Coturn/TURN management and validation;
- backup, portable export, restore rehearsal, and recovery workflows;
- migration tooling for supported legacy MEM installations;
- the host-installed `mem` operator CLI;
- English and German operator documentation;
- deterministic release tooling and supply-chain checks; and
- deterministic public-source preparation, exposure scanning, and isolated build/test verification.

Release artifacts are published separately through:

- https://github.com/message-easy-mode/mem-releases

Public source is published through:

- https://github.com/message-easy-mode/mem

## [0.1.0] - 2026-04-15

Historical Matrix Easy Mode foundation release.

This release established the original operator-facing baseline, including:

- the initial deployment and runtime model;
- the operator-first self-hosting posture;
- the staged infrastructure-first, application-second startup flow; and
- the initial documentation and release foundation.

The 0.1.x line predates the Message Easy Mode name and the current public-source publication workflow.
